# QubitKey AI Build Pack

This pack is the handoff for Cursor and Google Antigravity.

## Start here
1. Read `MASTER_BUILD_PROMPT.md`.
2. Create/open a Git repository named `qubitkey`.
3. Copy `AGENTS.md` into the repository root.
4. Copy `docs/PRODUCT_SPEC.md` and `docs/ARCHITECTURE.md` into `docs/`.
5. Give the coordinator prompt to Cursor Agent first. Require Milestone 0 planning only.
6. Review and approve the plan before implementation.
7. Delegate the specialist prompts in `prompts/` to separate branches/worktrees.
8. Integrate one vertical slice at a time and run tests.

## Tool split
- Cursor: coordinator, backend integration, code review and final merge.
- Antigravity: independent frontend implementation and browser QA, or a separate assigned workstream.
- GitHub: source of truth; use separate branches and pull requests.

Do not have both IDE agents edit the same working tree/files at the same time. Use separate worktrees or branches.

## Critical technical boundary
The simulator is educational, not physical quantum entropy. The MVP TOTP secret is generated by the OS CSPRNG. ML-DSA is a separate optional post-quantum signature demo. Do not claim the TOTP flow is quantum-resistant.

## Files
- `MASTER_BUILD_PROMPT.md`: full project brief and implementation plan.
- `AGENTS.md`: persistent instructions for coding agents.
- `docs/`: product and architecture specifications.
- `prompts/`: role-specific agent prompts.
